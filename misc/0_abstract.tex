\chapter{Abstract}
Static analysis of source code for dependency graph extraction traditionally requires implementations that are tightly coupled with the grammar of a specific programming language. This thesis project aims to define and formalize an analysis process capable of operating in a language-agnostic manner. Starting from Concrete Syntax Trees (CSTs) generated by generic parsers (such as Tree-sitter), this work formalizes the transformation of syntactic nodes into an abstract Component Tree and rigorously describes the rules for subsequent dependency resolution.

The correctness and consistency of the model are demonstrated by mapping the analysis functions to a formal Type System. Each phase of the process is modeled as a composition of strictly typed functions. Through the principles of functional semantics and polymorphism, the study demonstrates how extraction and resolution functions can handle constructs from different languages while ensuring Type Safety, termination, and the overall semantic coherence of the analysis pipeline.
